# news-db-service

A dummy Flask + SQLite app for Datadog SRE Workflow Automation demo.
Intentional DB schema bugs cause APM error spikes that trigger automated investigation and migration PRs.

## Intentional bugs

| Endpoint | Bug | Error |
|---|---|---|
| `POST /users` | Missing `email` column | `table users has no column named email` |
| `GET /users/<id>/profile` | Missing `email`, `profile` columns | `no such column: email` |
| `POST /publish/<id>` | Wrong column `is_published` | `no such column: is_published` |

## Setup

### Local (without Docker)
```bash
pip install -r requirements.txt
python migrations/init_schema.py
DD_SERVICE=news-db-service DD_ENV=prod ddtrace-run python app.py
```

### Docker
```bash
cp .env.example .env  # add your DD_API_KEY
docker-compose up --build
```

App runs on port **5001**.

## Trigger errors
```bash
# Spike all broken endpoints at once
curl http://localhost:5001/spike-errors

# Or hit individually
curl -X POST http://localhost:5001/users \
  -H "Content-Type: application/json" \
  -d '{"username": "test", "email": "test@test.com"}'

curl http://localhost:5001/users/1/profile

curl -X POST http://localhost:5001/publish/1
```

## Datadog monitor query
```
sum(last_5m):sum:trace.flask.request.errors{service:news-db-service}.as_count() > 5
```

## Workflow automation
When the monitor fires, the Datadog Workflow:
1. Triggers Bits AI SRE investigation
2. OpenAI generates an SQL migration
3. JavaScript builds `migrations/auto_fix.py`
4. GitHub: creates branch, commits migration, raises PR
5. Slack notifies the on-call team

## Migrations
All migrations live in `migrations/`. Run them in order:
```bash
python migrations/init_schema.py   # sets up initial (buggy) schema
python migrations/auto_fix.py      # auto-generated by workflow (fixes bugs)
```
